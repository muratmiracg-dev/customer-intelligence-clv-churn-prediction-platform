# Tableau workbook

Open `Customer_Intelligence_Dashboard.twb` with Tableau Desktop or Tableau
Public. If Tableau asks for the source file, point the connection to:

`../Data/Processed/customer_360.csv`

The workbook contains eight worksheets and three dashboard canvases covering
executive KPIs, RFM segments, CLV, churn risk, customer value-risk positioning,
campaign targeting, regional diagnostics and customer-level detail.

All data is synthetic and contains no real customer PII.
