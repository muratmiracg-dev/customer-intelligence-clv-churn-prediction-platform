# GitHub Yayınlama Rehberi

## 1. Repository Oluştur

Önerilen ad:

`customer-intelligence-clv-churn-prediction-platform`

Önerilen açıklama için `GitHub_Repository_Description.txt` dosyasındaki metni kullan.

Repository'yi başlangıçta private oluşturabilir, son kontrolden sonra public yapabilirsin.

## 2. GitHub Desktop ile Ekle

1. GitHub Desktop → **File → Add local repository**.
2. Proje klasörünü seç.
3. Repository henüz Git deposu değilse **create a repository** bağlantısına bas.
4. `main` dalını kullan.
