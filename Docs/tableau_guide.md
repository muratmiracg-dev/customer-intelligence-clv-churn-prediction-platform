# Tableau Guide

## Open the Workbook

Open `Tableau/Customer_Intelligence_Dashboard.twb` in Tableau Desktop or Tableau Public.

If Tableau cannot resolve the relative connection:

1. select **Data → Replace Data Source** or edit the existing text-file connection;
2. choose `Data/Processed/customer_360.csv`;
3. refresh the workbook.

## Delivered Views

The workbook contains:

- 8 analytical worksheets;
- 3 dashboards;
- customer value, risk, segmentation and campaign views.

## Publishing

Before publishing to Tableau Public:

- confirm that only synthetic data is included;
- hide unused fields;
- add a synthetic-data disclaimer;
- verify dashboard sizing on desktop and web;
- include a link back to the GitHub documentation.
